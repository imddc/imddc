### 最近在用的语言

<img src="assets/recent-languages.svg" alt="近 90 天公开仓库的提交加权语言排行；图中包含更新时间" width="100%">

<details>
<summary>这个排行怎么算？</summary>

统计近 90 天本人在个人公开仓库默认分支上的提交，按各仓库的语言代码量比例分摊并汇总。排除 fork 和归档仓库；不读取私有仓库，也不包含组织仓库。

这是近期公开活动涉及语言的**估算**，不代表编码时长、熟练度或实际修改行数所属语言。图中保留生成日期；没有公开活动时显示空状态。原始汇总见 [recent-languages.json](assets/recent-languages.json)。

更新：登录 GitHub CLI 后，在本仓库运行 `python3 scripts/recent_languages.py`，通过 PR 提交生成结果。也可以手动运行 Actions 的 **Refresh profile assets**，下载生成产物后审阅更新。

</details>
